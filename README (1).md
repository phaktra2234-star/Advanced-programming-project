# Advanced Programming — TP-01

## Student Grade Manager

This project is an original practice submission about Python foundations and clean coding. It uses a small student grade manager to demonstrate variables, constants, functions, classes, methods, modules, input validation, and readable Python style.

> **Important:** This project was prepared from a classmate's sample, not from the teacher's official instructions. Compare it with the assignment given in class and update the student details or requirements before submitting.

## Project files

- `TP01_Student_Grade_Manager.md` — explanations of the concepts and design.
- `student_grade_manager.py` — runnable Python program.
- `grade_utils.py` — helper functions in a separate module.

## Requirements

- Python 3.8 or newer
- No third-party packages required

## How to run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python student_grade_manager.py
```

The program demonstrates a sample grade report. It does not ask for personal information.
